Privacy Policy

Last updated: 3 September 2026

This page covers leonelki.com and the small personal software tools (such as "Leo Calendar MCP") that I, Leo Nelki, build and run for my own single-user, personal use.

This website

leonelki.com is a static site hosted on GitHub Pages. It does not use cookies, analytics, or any data-collection forms. GitHub may keep standard server access logs; I do not separately collect or store visitor data.

Personal tools (e.g. Leo Calendar MCP)

Tools like this connect only to my own Google Account, run only on my own devices, and are not distributed or offered to other users. They do not collect, store, sell, or share any data with any third party. Any data accessed (for example, Google Calendar events) is used solely to help me manage my own calendar through my own local tools, and is never transmitted anywhere beyond that local use.
