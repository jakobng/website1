Privacy Policy

Last updated: 16 October 2026

This page covers leonelki.com and the small personal software tools (such as "Leo Calendar MCP") that I, Leo Nelki, build and run for my own single-user, personal use.

This website

leonelki.com is a static site hosted on GitHub Pages. GitHub may keep standard server access logs.

The portfolio pages use Google Analytics only if you choose Accept in the visitor analytics prompt. It uses cookies to measure visits, pages viewed, referral sources and general device and location information. This data is processed by Google. Advertising personalization and Google signals are disabled.

If you decline, the Google Analytics tag is not loaded. Your choice is remembered in your browser's local storage. You can change it here at any time; withdrawing consent stops further Analytics collection and removes this property's Analytics cookies.

For details about Google's processing, see How Google uses information from sites that use its services.

Personal tools (e.g. Leo Calendar MCP)

Tools like this connect only to my own Google Account, run only on my own devices, and are not distributed or offered to other users. They do not collect, store, sell, or share any data with any third party. Any data accessed (for example, Google Calendar events) is used solely to help me manage my own calendar through my own local tools, and is never transmitted anywhere beyond that local use.
